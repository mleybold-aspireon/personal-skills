# Personal skills

Matthias Leybold's personal skills for Claude. Private; not company material, and not
loaded into the Aspireon Team plan. Aspireon's skills live in `Aspireon-AG/aspireon-skills`.

| Skill | Purpose |
|---|---|
| `executive-cv-and-cover-letter` | CV critique, quantified achievements, CV-to-job fit, tailored cover letters |
| `linkedin-recruiter-optimisation` | LinkedIn profile and activity for executive recruiter search |

## Using them

- **Personal Claude account:** upload the changed skill as a .zip in the Skills section of Settings
  (Claude can prepare the .zip after each change).
- **Claude Code:** `claude plugin marketplace add mleybold-aspireon/personal-skills`, then
  `claude plugin install personal@matthias-personal`.

## Rules

English only, no secrets or personal ID data, every change noted in `CHANGELOG.md`, and
`claude plugin validate .` must pass before merging.
